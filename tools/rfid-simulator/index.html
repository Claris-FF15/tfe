Simulateur Arduino + RFID

BadgeApp Demo

Arduino relié à un lecteur RFID et un écran LCD, entièrement virtuels. Glisse un badge sur le module RFID (ou clique dessus / valide au clavier) pour simuler un passage — une vraie requête part vers l'API BadgeApp, qui vérifie le badge et la permission d'accès à la porte, comme le ferait le vrai matériel. Aucune installation, aucun hardware requis.

Payload envoyé à POST /access-logs : { badge_uid, door_id }. La réponse attendue contient allowed (booléen), reason, user et door.
⚠️ GET /doors est protégé par authentification côté API — ce simulateur n'a pas de session connectée, donc l'ID de porte se saisit manuellement ci-dessus (ex : 1 = Porte principale, 2 = Serveur — adapte selon ta base).
⚠️ Si cette page est ouverte en fichier local (file://) ou servie sur un port différent de localhost:4200, vérifie que la configuration CORS du backend autorise son origine.
